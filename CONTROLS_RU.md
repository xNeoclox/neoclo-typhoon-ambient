# Управление Neoclo Typhoon Ambient Edition

**Статус**: экспериментальная модификация SuperParasites. Не новая аппаратная прошивка, испытанная на модуле.

## Переключение режимов
На панели Typhoon удерживай **TIME** для входа в режим выбора алгоритма, затем короткими нажатиями **TIME** переходи по слотам 1–8. Меню закрывается после бездействия. Алгоритм и состояние сохраняются штатными средствами SuperParasites.

Слоты по порядку:
1. Classic Clouds — оригинальный Clouds
2. Endless — WSOLA stretch, длинная замороженная текстура
3. Tape Memory — лупинг, tape flutter, постепенное затемнение
4. Spectral Drift — спектральный фриз с медленной модуляцией
5. Shimmer Cathedral — длинный Oliverb
6. Harmonic Drone — ResoNestor
7. Dissolve Delay — Kammerl slices, мягкая авто-нарезка
8. Spectral Ghost — spectral cloud

## Физические органы управления
PITCH — высота звука; POS — позиция/время; DENS — плотность/движение; SIZE — размер окна/лупа; TEXT — текстура/фильтрация. MIX — баланс сухого и обработанного сигнала (кроме Resonestor, где по оригиналу управляет искажением). PAN — стереопозиция; FDBK — обратная связь / параметр двигателя; RVB — реверб / модуляция в Oliverb. FREEZE — удержание звука; TRIG — ручной триггер. В режиме Dissolve Delay слайдер SIZE влияет на интервал автоматического захвата. CV-модуляция сохраняет стандартные входы Typhoon.

## Важно
FREEZE не означает независимую бесконечную запись во всех режимах. В частности, Endless сейчас является адаптацией WSOLA, не полноценным имитатором Blukac Endless Processor.
